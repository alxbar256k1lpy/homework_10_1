# Проект банковских операций

Этот проект помогает обрабатывать данные о транзакциях: фильтровать их по статусу и сортировать по дате.

## Разработанные функции

Все функции находятся в файле src/processing.py.

* filter_by_state(data, state) — возвращает только те операции, у которых статус совпадает со значением state (по умолчанию 'EXECUTED').
* sort_by_date(data, reverse) — сортирует операции по дате. По умолчанию сортирует от самых новых к старым (reverse=True).

## Примеры работы

Если передать список операций в функции, они вернут отфильтрованный или отсортированный результат.

Пример вызова фильтрации:
filter_by_state(input_data)

Пример вызова сортировки:
sort_by_date(input_data)

## Как запустить тест

Запустите файл src/processing.py напрямую в PyCharm. В консоль сразу выведутся результаты работы функций на тестовых данных.

## Тестирование проекта

В проекте используется фреймворк `pytest` для автоматического тестирования функционала маскирования, обработки виджетов и фильтрации банковских операций. 

Тесты покрывают 100% ветвей кода (branch coverage), используют параметризацию для проверки граничных случаев и глобальные фикстуры для генерации данных.

### Команды для запуска

1. **Запуск всех тестов:**
   ```bash
   pytest
   ```

2. **Запуск тестов в детальном (verbose) режиме:**
   ```bash
   pytest -v
   ```

3. **Запуск тестов с генерацией отчета о покрытии кода:**
   ```bash
   pytest --cov=src -v
   ```

Структура тестов расположена в папке `tests/`, глобальные тестовые данные и фикстуры находятся в файле `tests/conftest.py`.
